# ChatGal

**ChatGal** 是一款 **AI 互动 Gal** 安卓客户端：剧情、角色、立绘、事件、结局提示词全部来自可安装的 **内容包**，应用本身只做引擎与创作台。

你将扮演主角，和内容包里的角色在聊天式剧情里推进故事。数值（好感、信任等）由场景结束时的结算决定，你的每一次选择都会留下痕迹。

---

## 玩法简介

1. **选内容包**：主页选择已安装的故事包，点「新的开始」或读档进入。
2. **对话推进**：像聊天一样和角色说话；角色的台词、动作（括号内）由 AI 根据当前情景与你的输入生成。
3. **数值与结局**：每个情景结束时会结算好感、信任等变量；满足条件时走向不同结局或事件。
4. **存档**：单包多档，可在「内容包与存档」里管理；打不开的旧档会显示为占位，不会被静默删除。
5. **自己写故事**：内置「内容包创作台」，可用 JSONC 编写情景、角色、事件与出口。

### 核心机制（内容包视角）

| 机制 | 说明 |
|------|------|
| 情景（scene） | 一幕一段：背景、入场词、过场气氛、场景提示词、固定加减、结算、出口 |
| 出口（target） | 条件表达式决定下一幕；事件还可写选择题出口（choice） |
| 变量 | 注册后才能改写与判断；模型不能直接改数值 |
| 立绘 | 由立绘 agent 按节拍选图；聊天请求只写台词 |
| 记忆 | 多层记忆 + 关键词；回廊可查看触发关键词 |

## 常见问题

**Q：点开始后是 Mock 对话？**  
A：需要先在「设置 → 模型供应商」配置 OpenAI 兼容接口，或使用本地推理引擎（独立应用，本仓库不提供）。

**Q：内容包怎么安装？**  
A：主页「内容包与存档」→ 安装 `.chatgal` 文件；两个内置包启动时会自动安装。

**Q：旧存档打不开？**  
A：开发版存档结构升级较快，旧档会显示为只读占位。请新开一局。

**Q：为什么这个仓库没有源码？**  
A：本仓库是**公开发布与内容包开源**仓。应用源码维护在私有仓库，不在此推送。
